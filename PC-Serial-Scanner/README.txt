PC Serial Scanner
Yakastsi — rgb.by
========================================

Что это
-------
Портативная программа для Windows 10/11: максимально собирает серийные
номера и идентификаторы комплектующих ПК, чтобы сверить с гарантией.

В том числе:
• процессор (S/N если отдан + ProcessorId / PartNumber)
• КАЖДАЯ планка ОЗУ отдельно (#1, #2, …) со своим серийником
• материнка, BIOS, корпус, диски, мониторы, GPU, USB, сеть, батарея, TPM…

Установка не нужна. Можно копировать папку на флешку целиком.


Как запустить с флешки
----------------------
1. Скопируйте всю папку PC-Serial-Scanner на флешку.
2. На нужном ПК откройте флешку.
3. Правый клик по файлу PC-Serial-Scanner.bat →
   «Запуск от имени администратора» (рекомендуется).
4. Дождитесь окончания сбора.
5. Откроются отчёты HTML и TXT. Копии лежат в папке Reports.


Что смотреть в первую очередь для гарантии
------------------------------------------
• Материнская плата
• Планки ОЗУ — в отчёте отдельно «Планка ОЗУ #1», «Планка ОЗУ #2»…
• Накопители SSD/HDD/NVMe
• Процессор (ProcessorId + наклейка на коробке, если S/N скрыт)
• Серийник системы / корпуса / BIOS
• Мониторы, видеокарта (nvidia-smi)


Важно
-----
• У CPU заводской серийник Windows почти никогда не отдаёт — так делают
  Intel/AMD. Это не ошибка программы; смотрите ProcessorId и коробку.
• Две планки ОЗУ = две строки с двумя разными серийниками.
• Если NVIDIA-драйвер установлен, серийник GPU берём через nvidia-smi.
• Без прав администратора часть данных может быть пустой.


Файлы
-----
PC-Serial-Scanner.bat   — запуск двойным кликом (только латиница в bat)
PC-Serial-Scanner.ps1   — основная логика (не обязательно открывать)
Reports\                — сюда сохраняются отчёты TXT / CSV / HTML

Если bat «ломается» и пишет '... is not recognized» —
убедитесь, что скопирована свежая папка целиком с обновлённым .bat.
