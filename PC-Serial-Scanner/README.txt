PC Serial Scanner
Yakastsi — rgb.by
========================================

Что это
-------
Портативная программа для Windows 10/11: собирает серийные номера
комплектующих ПК (материнка, ОЗУ, диски, мониторы, BIOS, корпус и др.),
чтобы сверить их с гарантией продавца.

Установка не нужна. Можно копировать папку на флешку целиком.


Как запустить с флешки
----------------------
1. Скопируйте всю папку PC-Serial-Scanner на флешку.
2. На нужном ПК откройте флешку.
3. Правый клик по файлу PC-Serial-Scanner.bat →
   «Запуск от имени администратора» (рекомендуется).
4. Дождитесь окончания сбора.
5. Откроются отчёты HTML и TXT. Копии лежат в папке Reports.


Что смотреть в первую очередь для гарантии
------------------------------------------
• Материнская плата
• Модули ОЗУ (у каждого свой серийник)
• Накопители SSD/HDD/NVMe
• Серийник системы / корпуса
• Мониторы
• BIOS serial (часто совпадает с системным)


Важно
-----
• У процессора и многих видеокарт Windows часто НЕ отдаёт серийный номер —
  это ограничение производителей, не ошибка программы.
• Если NVIDIA-драйвер установлен, серийник GPU попробуем взять через nvidia-smi.
• Без прав администратора часть данных может быть пустой.


Файлы
-----
PC-Serial-Scanner.bat   — запуск двойным кликом
PC-Serial-Scanner.ps1   — основная логика (не обязательно открывать)
Reports\                — сюда сохраняются отчёты TXT / CSV / HTML
