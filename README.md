# Yakastsi — rgb.by

## PC Serial Scanner

Портативная утилита для **Windows 10/11**: максимально собирает серийники комплектующих для сверки с гарантией (CPU, каждая планка ОЗУ, диски, материнка, мониторы, GPU, USB и др.).

Папка: [`PC-Serial-Scanner/`](PC-Serial-Scanner/)

### Запуск с флешки

1. Скопируйте папку `PC-Serial-Scanner` на флешку.
2. На ПК: правый клик → **Запуск от имени администратора** по файлу `PC-Serial-Scanner.bat`.
3. Отчёты появятся в `PC-Serial-Scanner/Reports/` (HTML, TXT, CSV).

Сделано: **Yakastsi — rgb.by**
